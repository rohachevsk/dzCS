# dzCS — домашки по C#

Один репозиторий — много маленьких программ: от первых массивов до коллекций,
делегатов и событий.
Каждая работа живёт в своей папке, собирается и запускается одной командой.

> Если вы читаете это как проверяющий: здравствуйте! Всё решение собирается
> без ошибок и предупреждений, тесты зелёные, а комментарии в коде — только там,
> где без них никак.

## Стек

- **.NET 10** (консольные проекты `net10.0`, WinForms-проект — `net10.0-windows`)
- **C#** с включенными `Nullable` и `ImplicitUsings`
- **xUnit** — там, где задание требовало тесты

## Быстрый старт

```powershell
# собрать всё решение
dotnet build dzCS.slnx

# прогнать все тесты
dotnet test dzCS.slnx

# запустить конкретную работу
dotnet run --project "02.11 - Boxing, Unboxing, collections"
dotnet run --project "28.10(Делегати, події, методи розширення)"
dotnet run --project "27.10 Делегати"
dotnet run --project "21.10"

# WinForms-проект 26.10 открывает окно
dotnet run --project "26.10"
```

Некоторые программы ждут ввода с клавиатуры — это не баг, а условие задания.
В проектах с меню (`27.10 Делегати`, `28.10(...)`, `02.11`) внутри есть
собственное подменю: можно смотреть демо, а можно добавлять элементы вручную.

## Как устроена домашка

```
MM.DD - Название/
  Primer.csproj   # имя проекта — латиницей без пробелов
  Program.cs      # точка входа + консольное меню
  *.cs            # классы задания
```

Имя папки — дата и тема (`MM.DD - Название` или `MM.DD(Тема)`), в таком виде
работы удобно листать и искать. `bin/obj` в git не попадают.

## Как добавить новую работу

```powershell
# 1. Создать консольный проект
dotnet new console -n Primer -o "10.21 - NovayaTema"

# 2. Добавить в решение
dotnet sln dzCS.slnx add "10.21 - NovayaTema/Primer.csproj"

# 3. Запустить
dotnet run --project "10.21 - NovayaTema"
```

## Почему всё в одном репозитории

Потому что одна история — приятнее, чем сорок архивов с именами `final_final_v2`.
Каждая тема добавляет папку, а не новый репозиторий.
