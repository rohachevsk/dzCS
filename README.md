# dzCS — домашки по C#

Один репозиторий — много маленьких программ: от первых массивов до собственных индексаторов.
Каждая работа живёт в своей папке, собирается и запускается одной командой.

> Если вы читаете это как проверяющий: здравствуйте! Здесь всё написано вручную,
> собирается без ошибок и предупреждений, а комментарии в коде — только по делу.

## Что внутри

| Папка | Тема | Что посмотреть |
|---|---|---|
| `10.07 - Osnovi` | Массивы и строки | Общие элементы двух массивов без повторов, переворот каждого слова в предложении, подсчёт гласных |
| `10.14 - Primer` | Первый проект | Точка входа и структура домашки |
| `12.10 Massive methods` | Классы и методы | «Веб-сайт», «Журнал», «Магазин»: поля, ввод/вывод, доступ к полям через методы |
| `13.10` | Свойства и валидация | «Заграничный паспорт»: проверки полей и дат в конструкторе, статический счётчик, `ToString` |
| `14.10` | Композиция и агрегация | «Университет»: студенты, преподаватели, курсы и адреса |
| `20.10` | Перегрузка операторов | «Сотрудник» (зарплата, `+ - ++ -- == != < > Equals`) и «Матрица» (`+ - *`, `== != Equals`, индексатор) |
| `21.10(Classwork)` | Работа со строками | Пять задач: подстрока в словах, слова на заданную букву, самое длинное слово, слова на заданный конец, поиск и подсчёт вхождений с индексами |
| `21.10` | Интерфейсы и records | Система обработки документов: `ITextProcessor`, `Document`/`Article`/`Report`, `record`-статистика, отчёт на `StringBuilder`, `with`, консольное меню |

## Быстрый старт

```powershell
# собрать всё решение
dotnet build

# запустить конкретную работу
dotnet run --project "21.10"
dotnet run --project "21.10(Classwork)"
dotnet run --project "20.10"
dotnet run --project "10.07 - Osnovi"
```

Некоторые программы ждут ввода с клавиатуры — это не баг, а условие задания.

## Как устроена домашка

```
MM.DD - Название/
  Primer.csproj   # имя проекта — латиницей без пробелов
  Program.cs      # точка входа
  *.cs            # классы и логика
  README.md       # число, тема, список задач
```

Имя папки — `MM.DD - Название`, в таком виде работы удобно листать и искать.

## Как добавить новую работу

```powershell
# 1. Создать консольный проект
dotnet new console -n Primer -o "10.21 - NovayaTema"

# 2. Добавить в решение
dotnet sln dzCS.slnx add "10.21 - NovayaTema/Primer.csproj"

# 3. Запустить
dotnet run --project "10.21 - NovayaTema"
```

## Почему всё в одном репозитории

Потому что одна история — приятнее, чем сорок архивов с именами `final_final_v2`.
Каждая тема добавляет папку, а не новый репозиторий.
